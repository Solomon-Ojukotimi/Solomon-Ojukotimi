## 🚀 About Me

I’m a **Data Engineer and Data Scientist** who enjoys turning messy data into reliable systems, useful insights, and practical solutions.

My work sits at the intersection of **data engineering, cloud technologies, analytics, and machine learning**. I build and work with ETL/ELT pipelines, data platforms, cloud data services, and analytical solutions that help move data from raw sources to something people and applications can actually use.

On the engineering side, I work with technologies such as **Python, SQL, PySpark, Kafka, Databricks, AWS, Azure Data Factory, Snowflake, dbt, Docker, and CI/CD**. On the data science side, I work with **machine learning, deep learning, statistical analysis, A/B testing, and predictive modeling**.

I’m particularly interested in building scalable data pipelines, modernizing data platforms, working with cloud-based architectures, and finding practical ways to use data and machine learning to solve real-world problems.

And when I’m not working with data, you’ll probably find me analyzing football. ⚽
Apparently, I like looking for patterns whether the dataset is a database or a football match.
